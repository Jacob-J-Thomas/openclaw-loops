## Evidence boundaries

Real provider and native browser evidence is separate from deterministic adapters. Sampling values described as transmitted were observed at the public host boundary; that is not proof of provider enforcement. A settled local promise or worker is not proof that a remote provider stopped. Gateway connection scopes are not independent human-principal identities. Separate Gateways provide customer state boundaries; one shared library is not tenant isolation.

The original POC archive and historical receipts remain private or in [verification history](VERIFICATION.md). Raw profiles, transcripts, logs and customer fixtures are not published. No model allowlist, provider implementation, bypass of host policy or hidden restriction is introduced to disguise an unavailable contract. Stable 1.0 remains gated on the revised in-scope requirements, including practical accessibility and actual registry qualification. Missing optional host enhancements do not block that release.
