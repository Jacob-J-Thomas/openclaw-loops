# Delivery status

Loops remains an external OpenClaw plugin with the existing `loops-poc` runtime identity and migration path. The nine-node 1.0 palette is implemented. Real runtime, command, native editor, storage-fault and isolated-deployment qualification is recorded below. **This is still an alpha; stable 1.0 has not been published.** Required public host contracts remain open. The owner deferred remaining accessibility work on September 20, 2026; that deferral does not mean accessibility acceptance or an API blocker.

The active scope is the standalone plugin's requirements R01–R25 and packages P0–P6 in [the delivery plan](DELIVERY_PLAN.md). X01–X29 and SDK05 remain a later expansion roadmap. Public OpenClaw contributions belong in separate repositories/PRs; host patches, private provider clients and personal profiles are excluded from this repository and package. GitHub native issue edges and owner acceptance receipts are authoritative; the [roadmap index](ROADMAP_ISSUES.json) preserves the initial 116 issues.

## Evidence boundaries

Real provider and native browser evidence is separate from deterministic adapters. Sampling values described as transmitted were observed at the public host boundary; that is not proof of provider enforcement. A settled local promise or worker is not proof that a remote provider stopped. Gateway connection scopes are not independent human-principal identities. Separate Gateways provide customer state boundaries; one shared library is not tenant isolation.

The original POC archive and historical receipts remain private or in [verification history](VERIFICATION.md). Raw profiles, transcripts, logs and customer fixtures are not published. No model allowlist, provider implementation, bypass of host policy or hidden restriction is introduced to disguise an unavailable contract. Stable 1.0 remains gated on the open release requirements, including the deferred accessibility requirement.
